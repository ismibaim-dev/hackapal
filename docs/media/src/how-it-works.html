How hackapal works

The AI does the shopping. The human does the paying. The server decides every price.

1

Ask Claude

Claude reaches the shops over MCP: list_shops, list_products, then one create_order for the whole cart.

2

One PayPal checkout

The server prices the cart and creates one Orders v2 order with a purchase unit per seller, each with that seller's payee.

3

Buyer approves

Only the human pays. PayPal collects the delivery address. One capture call, one capture per seller.

4

Each seller paid

Money lands in each seller's own PayPal account. Each shop's Telegram bot sends an order card: items, address, contact, note.

Prices from the serverThe model sends product ids and quantities only; integer cents end to end.
Safe retriesPayPal-Request-Id on every POST, verified webhooks, stock taken exactly once.
Paid means PayPal says soClaude says "paid" only when get_order_status is COMPLETED.
